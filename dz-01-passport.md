# ДЗ-1. Паспорт продукта

**Обучающийся, группа:** Патраков Юрий, MFAI-02

## Технология

Приложение для краткосрочной аренды квартир с моделью рекомендации цены. Когда владелец добавляет квартиру, он указывает город, район, площадь, число комнат и гостей, удобства и даты сдачи. Модель предлагает цену за ночь; владелец может принять её или указать свою.

## Вариант B2C — продукт для человека

**Кто пользователь:** частный владелец пяти квартир в Санкт-Петербурге. Раньше он сдавал их на долгий срок, а теперь хочет самостоятельно запустить посуточную аренду.

**Повод обращения:** после освобождения квартир владелец готовит первые объявления для посуточной сдачи и не знает, какую цену назначить каждой квартире. При заполнении объявлений приложение сразу предлагает ставки за ночь.

**Кто решает, кто платит и за что:** владелец сам принимает решение и платит из личных средств за рекомендации по своим пяти квартирам, например по подписке на месяц.

## Вариант B2B — продукт для организации

**Кто пользуется:** риелтор из управляющей компании, которая сдаёт посуточно около 40 квартир в Санкт-Петербурге.

**Повод обращения:** перед летним сезоном нужно обновить цены сразу на весь портфель квартир и подготовить тарифы по датам. Риелтор загружает список объектов и получает рекомендации для каждого из них.

**Кто решает о покупке:** операционный директор управляющей компании после оценки пользы для команды.

**Кто платит и за что:** компания из бюджета на управление объектами. Она оплачивает подписку по числу квартир за массовый расчёт и выгрузку рекомендованных цен.

## Проверка: чем B2B отличается от B2C

В B2C частный владелец запускает посуточную сдачу своих пяти квартир, сам выбирает сервис и платит за рекомендации. В B2B сотрудник перед сезоном пересчитывает цены десятков квартир, которыми управляет компания; покупку утверждает директор, а платит организация. B2B-версии нужны загрузка портфеля и выгрузка тарифов для работы команды.
